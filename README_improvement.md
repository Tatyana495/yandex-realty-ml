# Сравнение Ridge и CatBoost

Первой моделью для оценки стоимости квартир была Ridge-регрессия. После её обучения и проверки на отложенной выборке средняя абсолютная ошибка составила 8,48 млн рублей. Для табличных данных с выраженными нелинейными зависимостями была дополнительно обучена модель CatBoost.

## Изменения

В `src/ml/features.py` добавлены признаки:

- `relative_floor` — отношение этажа квартиры к этажности дома;
- `living_share` — доля жилой площади в общей;
- `kitchen_share` — доля площади кухни;
- `area_per_room` — общая площадь на комнату.

В `src/ml/train.py` добавлено обучение `CatBoostRegressor` с функцией потерь `MAE`. Для выбора числа деревьев исходная обучающая выборка дополнительно разделяется по `building_id`. Затем итоговая модель обучается на всей обучающей выборке. Тестовые данные в подборе параметров не используются.

В сохранённом артефакте `models/price_model.joblib` находятся CatBoost, Ridge, медианная модель и сведения о признаках. Это позволяет сравнивать алгоритмы на одной тестовой выборке.

## Результаты

Тестовая выборка: 26 362 квартиры.

| Модель | MAE, ₽ | RMSE, ₽ | R² |
|---|---:|---:|---:|
| DummyRegressor (медиана) | 10 252 751,51 | 36 475 210,54 | −0,0426 |
| Ridge | 8 480 024,84 | 21 681 294,89 | 0,6316 |
| CatBoost | **4 205 322,58** | **15 843 854,69** | **0,8033** |

При использовании CatBoost MAE снизилась на 50,4% относительно Ridge. Для итоговой модели использовано 735 деревьев.

Несмотря на улучшение общих метрик, большие абсолютные ошибки остаются возможными, особенно для объектов с высокой стоимостью. Значения тестовых метрик не следует использовать для дальнейшего подбора гиперпараметров: новые варианты модели нужно сравнивать на отдельной валидационной части обучающих данных.

## Воспроизведение

Из корня проекта с активированным окружением:

```powershell
python -m pip install -r requirements-stage3.txt
python -m dvc repro
python -m dvc metrics show
```

Обновлённая модель и другие артефакты DVC загружаются в настроенное S3-хранилище командой `python -m dvc push`.
